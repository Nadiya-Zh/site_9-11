Сайт «Мої опори · 9–11 клас»

Як відкрити: розпакуйте архів і відкрийте index.html у браузері. Для розміщення в інтернеті завантажте всю папку на будь-який статичний хостинг (наприклад, GitHub Pages, Netlify чи сервер закладу).

Налаштування: файл assets/config.js. Параметр unlockSensitive: true вимикає екран підтвердження для чутливих тем 17 і 20 (для психолога, що проводить заняття); hideSensitive: true повністю ховає ці теми зі списку.

Приватність: сайт не збирає персональних даних і не використовує аналітику; прогрес зберігається лише в браузері користувача (localStorage).
Зауваження: бібліографічні дані в джерелах уроків подано за знаннями автора без звірки з першоджерелами; перед публічним розміщенням перевірте їх. Матеріали — просвіта й профілактика, не терапія.
